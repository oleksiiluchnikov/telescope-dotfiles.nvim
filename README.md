# telescope-dotfiles

A [telescope.nvim](https://github.com/nvim-telescope/telescope.nvim) extension to search and edit dotfiles.

## Installation

Install using your favorite plugin manager:

```lua
{
  'nvim-telescope/telescope-dotfiles.nvim',
  dependencies = { 'nvim-telescope/telescope.nvim' },
}
```

## Usage

```lua
require('telescope').load_extension('telescope-dotfiles')
```
